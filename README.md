# C by C — Célébrations by Chirel

Site vitrine public de C by C, dédié aux invitations digitales élégantes et personnalisées.

## Direction artistique

- Logo officiel doré conservé
- Palette : ivoire, crème, champagne, or et bronze
- Style élégant, chaleureux et haut de gamme
- Design responsive, ordinateur et mobile

## Pages prévues

- Accueil
- À propos
- Comment ça fonctionne ?
- Contact
- Mentions légales et politique de confidentialité

Le catalogue, les comptes clients et le paiement sont volontairement hors périmètre pour cette première version.

## Stack prévue

Nuxt 3 · Vue · CSS responsive
